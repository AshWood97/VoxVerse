1. Warm Paper

参考气质：Claude / Anthropic

关键词：温暖、纸感、低刺激、适合长时间阅读。
适合 VoxVerse 的聊天、英语练习、角色陪伴场景。

视觉规则：

背景：象牙白、米白、浅暖灰。
主色：陶土橙、褐红、暖棕。
卡片：轻微阴影，不要玻璃效果。
字体：Inter / system font，字重不要太重。
气泡：AI 气泡接近纸张颜色，用户气泡用低饱和暖橙。
适合功能：Free Talk、记忆、关系卡、反馈面板。

这套应该作为 默认推荐皮肤之一，因为它最适合长文本聊天。Claude 官方页面本身也强调写作、文档、代码、Artifacts 等创作型使用场景，VoxVerse 的角色对话和语言学习与这种“工作台+纸感”的方向比较贴合。

2. Aurora Glass

参考气质：Gemini / Google AI

关键词：渐变、柔光、多彩但干净、AI 感明显。

视觉规则：

背景：深蓝黑 / 淡灰白两套。
主色：蓝、紫、青、粉的渐变。
卡片：柔和半透明，但不要过度玻璃。
按钮：大圆角胶囊。
动效：hover 时轻微浮起、渐变流动。
适合功能：模型切换、语音状态、AI 反馈、学习报告。

这套更适合做 科技感展示皮肤，但不要全屏彩虹，否则很快显廉价。可以只让顶部状态条、发送按钮、活跃标签使用渐变。

Google 的 Material Design 3 本身强调颜色、形状、动效和可表达性，做 Gemini 气质时可以参考 Material 的方向，但不要照搬。

3. Code Console

参考气质：Codex / developer agent

关键词：开发者、任务队列、终端、代码审查、执行状态。

视觉规则：

背景：近黑、石墨灰。
主色：绿色 / 青色 / 蓝色，不要霓虹过头。
字体：正文 Inter，状态和代码区域用 monospace。
气泡：更像 log card，而不是传统聊天气泡。
组件：任务卡、执行状态、测试结果、引用、diff 风格。
适合功能：Agent tools、diagnostics、audit、CLI 状态、未来自动化任务。

Codex 官方介绍里强调 cloud sandbox、多任务并行、测试输出、终端日志、PR review、实时进度等，这些都不是普通聊天 UI，而是“任务执行工作台”UI。
所以这套皮肤不该只是黑色主题，而要把 状态、证据、执行过程 做出来。

4. Dark Signal

参考气质：Grok / X / Cyber interface

关键词：黑、锐利、高对比、实时信息流、社交平台感。

视觉规则：

背景：纯黑或极深灰。
主色：白、浅灰、少量电蓝。
卡片：边框清晰，阴影减少。
按钮：扁平、紧凑、偏硬朗。
信息流：更像 timeline / feed。
适合功能：历史会话、角色动态、实时反馈、系统通知。

这套适合做成 夜间高对比皮肤。但要注意：Grok/X 气质很强，如果做得太像 X，会压过 VoxVerse 自己的产品身份。建议只取“黑底 + 实时 feed + 锐利边框”。

5. Liquid Frost

参考气质：Apple / macOS / visionOS

关键词：玻璃、毛玻璃、圆角、空间层级、柔和高级。

视觉规则：

背景：浅灰、冰蓝、银白。
卡片：半透明、blur、细边框。
圆角：较大，18px–28px。
阴影：大而柔，不要脏。
动效：轻微弹性、淡入淡出。
适合功能：设置页、角色卡、弹窗、关系卡。

Apple HIG 是这类方向的基础参考；当前 Apple 系统也已经走向更统一的玻璃化视觉语言。
这套非常容易做出高级感，但也容易出问题：透明层太多会影响可读性。VoxVerse 是文字密集产品，玻璃效果只能用于容器和浮层，不要用于正文气泡。

6. Graphite Minimal

参考气质：Vercel / Linear / shadcn/ui

关键词：黑白灰、极简、细边框、开发者审美、SaaS 高级感。

视觉规则：

背景：白 / 黑都可以。
主色：黑白灰为主，只有一个强调色。
卡片：1px 边框，几乎无阴影。
字体：Inter / Geist Sans / monospace 辅助。
组件：紧凑、规整、留白精准。
适合功能：全局默认专业皮肤、仪表盘、设置页。

Vercel 的 Geist 明确是面向一致 Web 体验的设计系统，包含高对比色彩、网格、开发者字体和组件体系。
shadcn/ui 也强调“可自定义、可扩展、作为设计系统基础”，这和 VoxVerse 当前不用重型 UI 框架的状态很匹配。

这套我建议作为 v0.4 的主推皮肤。原因很简单：高级、克制、实现成本低。

7. Enterprise Carbon

参考气质：IBM Carbon

关键词：企业级、数据系统、AI 工具、冷静、可信。

视觉规则：

背景：深蓝黑 / 浅灰。
主色：IBM 蓝、青蓝、白。
卡片：清晰分区，弱阴影。
组件：表格、状态、标签、信息密度高。
适合功能：Stats、Audit、Diagnostics、Agent tools。

IBM Carbon 是开源设计系统，覆盖代码、设计工具、组件、人机界面规范等，适合拿来做“企业级 AI 工作台”的参考。
如果 VoxVerse 后面要加 Agent、数据面板、学习统计，这套很有用。

8. Primer Dev

参考气质：GitHub Primer

关键词：仓库、开发协作、issue、PR、badge、代码项目。

视觉规则：

背景：GitHub dark / light。
主色：蓝、紫、绿。
卡片：repo card、issue card、badge。
字体：系统字体 + monospace。
适合功能：角色市场、插件市场、工作流、工具列表。

GitHub Primer 是 GitHub 自己的设计系统，覆盖 Product UI、Brand UI、Octicons、accessibility、tokens 等。
这套特别适合 VoxVerse 的“角色市场”“工具市场”“插件列表”。

9. Creative Spectrum

参考气质：Adobe Spectrum / 创作工具

关键词：专业软件、工具面板、中性灰、创作者工作台。

视觉规则：

背景：中性深灰。
主色：蓝紫 / 靛蓝。
布局：左工具栏、中间工作区、右属性面板。
卡片：少圆角，更多专业软件感。
适合功能：角色编辑器、Prompt 编辑、场景编辑、语音设置。

Adobe Spectrum 是 Adobe 的设计系统。虽然官方文档页面需要 JS，但方向可以概括为专业创作软件的中性工作台。
VoxVerse 如果后面要做角色编辑、技能编辑、Prompt 模板，这套很合适。

10. Luxury Console

原创方向：高端金融 / 奢侈品后台 / 黑金界面

关键词：黑金、墨绿、香槟金、精致、少量装饰。

视觉规则：

背景：曜石黑、深墨绿。
主色：香槟金 / 古铜金。
字体：标题可以用 serif，正文仍用 sans。
卡片：细金边、低透明度渐变。
适合功能：会员感、收藏角色、成就系统、关系等级。

这套不是最实用，但非常适合做“高级感展示皮肤”。注意不要做成土豪金，金色只能作为细线、图标、active 状态。

除了 claude / gemini / codex / grok / apple / 像素风，还值得考虑这些风格

我按优先级排：

风格	高级感	实用性	适合 VoxVerse 吗

Warm Paper / Claude 风	很高	很高	最适合聊天
Apple Liquid Glass 风	很高	中高	适合弹窗和卡片
Carbon Enterprise 风	高	很高	适合数据和 Agent
GitHub Primer 风	高	很高	适合开发者/插件市场

Material 3 Expressive 风	中高	高	适合轻快 AI 产品
